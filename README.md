# Todo App

A simple, responsive Todo App built with HTML, CSS, and vanilla JavaScript.

Manage your daily tasks with a clean dark interface and a purple accent theme.

## Features

- Add new tasks using a modal form
- Edit existing tasks
- Delete tasks
- Mark tasks as completed or uncompleted
- Filter tasks by status
- Search tasks by title
- Track total and completed tasks
- Save tasks in the browser using Local Storage
- Responsive layout for desktop and mobile devices
- Interactive buttons and hover effects

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser Local Storage

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No build tools or external JavaScript libraries are required.

## Data Storage

Tasks are saved in the browser's Local Storage, so they remain available after refreshing the page in the same browser and origin.

The data is stored locally and is not synchronized across devices.
